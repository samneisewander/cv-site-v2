Welcome to the first post on the new site. This is a place for me to write things
down — short notes, longer essays, and the occasional deep dive.

## Why a new site

The old site was hard to update. Every change meant touching templates. This
version is driven entirely by Markdown: to publish something, I add a folder with
an `index.md` inside `content/articles/` and commit it.

## How it's built

The site is generated by [Hugo](https://gohugo.io/), hosted on Firebase, and
deployed automatically whenever I push to `main`. The whole pipeline is a single
GitHub Actions workflow:

```yaml
- name: Build
  run: hugo --minify
- name: Deploy
  uses: FirebaseExtended/action-hosting-deploy@v0
```
